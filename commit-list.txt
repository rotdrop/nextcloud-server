    Avoid excessive mount cache shootdown for authenticated and non-shareable mounts.

    This commit adds two new mount-flags 'authenticated' and
    'enable_sharing' which are used to avoid a mount-cache shoot-down for
    file-systems which by design cannot be shared of need authentication.

    This affects the way UserMountCache::registerMounts() cleans up the
    mount-cache:

    - non-shareable mounts are left in the cache if the mounts are
      registered for another user the currently logged on user
    - authenticated mounts are left in the cache if credentials are not
      available.

    The use case are special authenticated and non-shareable virtual
    file-systems.
